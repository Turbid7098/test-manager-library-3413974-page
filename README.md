# Manager Library — sitio público

Sitio estático de presentación del proyecto Manager Library. No necesita Node.js, compilación, base de datos ni conexión a la API.

## Ejecutar localmente

Abre `index.html` en un navegador o sirve esta carpeta con cualquier servidor estático. Por ejemplo:

```powershell
python -m http.server 4173
```

Después visita `http://localhost:4173`.

## Contenido

- Presentación del producto y navegación por secciones.
- Funciones de catálogo, socios, préstamos y seguimiento de vencimientos.
- Enlaces a los repositorios públicos de la aplicación y su documentación.
- Maquetación adaptable a móvil y escritorio, navegación móvil accesible, metadatos sociales y favicon SVG.

La página no carga bibliotecas, fuentes ni recursos de terceros y no realiza solicitudes a la API.
